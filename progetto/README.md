# Progetto — Pipeline didattica

Il codice dell’applicazione si trova in **`backend/`**.

Documentazione completa (struttura cartelle, avvio, `.env`, API, agenti):  
→ [`backend/README.md`](backend/README.md)

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Poi apri http://127.0.0.1:8000/
